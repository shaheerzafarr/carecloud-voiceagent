Voice Agent Tool Functions

Vapi executes these tools via HTTP POST to the backend webhook:

checkExistingPatient

Queries database by 10-digit caller phone number. If found, greets patient by name and retrieves their records.

registerPatient

Captures all 17 demographic, contact, address, emergency, and insurance fields with duplicate phone detection (409 Conflict).

scheduleAppointment

Books appointment slot with doctor, date, time, and visit reason linked to the patient UUID.
